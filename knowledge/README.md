# Knowledge

Your domain data — people, goals, business context, reference material. Organize by domain
(`knowledge/<domain>/`); keep notes on a person or entity together in their own folder under the
relevant domain. Starts empty.

## Domains

This table is the one list of domains. Every tree that groups by domain — this one, `projects/`,
`apps/` — uses these names and no others. A tree may omit a domain it has nothing for; it may not
invent one. A new domain is an edit to this table first, then the other trees may use it. The rows
below are examples: replace them with your own.

| Domain | What it is | knowledge |
|---|---|---|
| `work` | the business you run or work in — clients, operations, products | `work/` |
| `web` | websites and web apps you build or maintain | `web/` |
| `infra` | the hosts — network, servers, containers — and the tooling that runs on them | `infra/` |
| `ai` | the agent system — skills, harnesses, models; not the hosts they run on | no records; its state is the journal, `decisions/` and the skills' `state/` folders |
| `finance` | personal finance — budget, investments, tax | `finance/` |
| `health` | health tracking and records | `health/` |
| `home` | the house, vehicles, family life | `home/` |
| `people` | one note per person | `people/` |
